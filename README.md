## Descripción
Este proyecto consiste en un sistema de paquetería implementado en Java. Modela los datos de un paquete, evalúa reglas de negocio mediante una clase utilitaria estática para cotizar tarifas por rango de peso y determina la obligatoriedad de un seguro de envío por dimensiones o valor monetario.
